# 全书错误禁令清单（持续累积，写下一章前必读）

状态：ACTIVE / 只增不删 / 跨章累积
版本：2026-10-20 按作者指令固定（每章建修改记录、下一章不重犯已登记错误）
依据：每轮番茄读者诊断 + 作者拍板确认的错误，逐条登记

使用规则：写任何一章前，先读本清单逐条自查；清单中错误在新章重犯 = 一次流程违规，须在当章修改记录中登记违规并说明。已修条目保留不删（供复查与防止反复）。

## ERR-001 章｜女主太清醒，嘴比心稳

- 出处：CH001 R046—R047 时代；CH002 R012 复发
- 错误描述：女主全程掌控场面、台词精准拆解，读者要的"她被场面撕扯、真慌一瞬"缺失；手在抖但嘴太稳，狠话连发，两个男人依次松手。
- 正确做法：女主每章至少一次生理级失控（心跳/手抖/垂眼/呼吸乱），慌完立即收回掌控；台词错位——身体先乱、嘴还硬。
- 状态：CH001 已修（R049—R055），CH002 R012 复发，R013 修。

## ERR-002 章｜雄竞是回合制，不是同场竞技

- 出处：CH001 R054 之前；CH002 R012 复发（"周递卡+容罚站"）
- 错误描述：两个男人一个握完另一个握、一个递卡另一个旁观，从未同一帧同时面对她；一退一进缺失，雄竞没开始就结束。
- 正确做法：雄竞必须同场——两个男人在同一帧同时面对她；一个退时另一个必须进；各有各的定位（黎把她当棋局/容把她当人）。
- 状态：CH001 已修（R055 名场面），CH002 R012 复发，R013 修。

## ERR-003 章｜情感高光被事件抢台

- 出处：CH001 R046 时代；CH002 R012（"恨也是感情"刚起就被周妄生切断）
- 错误描述：全章最好的情感台词/瞬间没有后果（她"不能接"之后没有然后），紧接着的事件（递卡/商战）把情感高点打断且不再收束。
- 正确做法：情感高光必须给后果（身体先于理智的动作/被逼出的话），事件排在其后；一个章两个高光时各自要有落点，禁止互相稀释。
- 状态：CH002 R012 待修，R013 修。

## ERR-004 章｜结尾心句复读上章，无新名场面

- 出处：CH002 R012 结尾（"更想被哪一只手拉住"≈上章"更恨哪一只还是更放不下哪一只"）
- 错误描述：结尾没有新动作/新决定/新细节，只把旧心句换个说法；情感钩变成回声，读者感觉感情线一版没动。
- 正确做法：结尾情感钩必须升级——她做了什么（动作/决定/身体细节），不是她又想了什么；旧心句可呼应但必须让位于新东西。
- 状态：CH002 R012 待修，R013 修。

## ERR-005 章｜女主在感情线上只被动接收，主动性归零

- 出处：CH002 R012（对容既白全程"睫毛动/别开眼/手指停/声音发涩"，零主动提问）
- 错误描述：女主主动落子全在商战线，感情线上是纯接收端；方法论刀2（永远主动落子）失效。
- 正确做法：感情线也必须女主主动——她自己的问题/她的决定/她把球抛回给对方，不是每句都是回应。
- 状态：CH002 R012 待修，R013 修。

## ERR-006 章｜雄竞赢家变圣父，侵略性残留缺失

- 出处：CH002 R012（容既白从"松不开的是你"变成全程忏悔守护、零身体接触）
- 错误描述：上一章赢了雄竞的男人，下一章直接转纯爱赎罪模式；NP要的是赢家带侵略性残留（会靠近、会逼、会有张力），不是感动式守护。
- 正确做法：赢家后续章节保留攻击性/靠近/张力；忏悔可以，但必须与"他还在追她"并置。
- 状态：CH002 R012 待修，R013 修。

## ERR-007 章｜作者旁白替女主感受

- 出处：CH002 R012（"这是他的方式，把全世界铺成她的出口"）
- 错误描述：作者跳出来解释角色意图，破坏代入；动作本身的分量被解释推开。
- 正确做法：删解释句，让动作/细节说话；需要时改写成女主视角的观察。
- 状态：CH002 R012 待修，R013 修。

## ERR-008 章｜事件信息给了，关系后果没给

- 出处：CH002 R012（周妄生"我以为你死了"说完就被拒卡打断，无反应无追问无后果）
- 错误描述：旧事信息差（他以为她死了）点火即熄，读者刚被吊起就切场景。
- 正确做法：事件信息必须带关系后果——女主的反应/追问/记下，至少一句。
- 状态：CH002 R012 待修，R013 修。

## ERR-009 章｜两章男主零身体接触女主，NP干渴

- 出处：CH002 R012（全章无任何男人靠近女主的身体动作）
- 错误描述：NP文读两章，男主没碰过女主；身体张力全缺，深夜独处/旧居重聚场景天然该有靠近。
- 正确做法：每章至少一次身体靠近/张力（握/拦/逼近/退无可退），不写细节但要有接触点。
- 状态：CH002 R012 待修，R013 修。

## ERR-010 章｜"惩罚/约定"公事化，不带情绪

- 出处：CH002 R012（"这页纸我先看三天，三天后来取答案"像合同条款）
- 错误描述：她给他的惩罚/约定冷得像行政通知，读者不替他捏汗。
- 正确做法：惩罚/约定必须带情绪化附加（戳他的条件/她自己都没料到的要求），让读者心悬。
- 状态：CH002 R012 待修，R013 修。

## ERR-011 章｜黎长聿只谈钥匙不谈人（反派CP线情感薄）

- 出处：CH002 R012（短信"我手里这把钥匙你还没还"纯谜钩，无个人痕迹）
- 错误描述：黎长聿是17条CP之一（热手男主），只给谜不给"他还在乎她"的痕迹，读者觉得他眼里只有筹码。
- 正确做法：反派线隐晦≠情感线隐晦；每条CP线至少保留一点个人痕迹（他为什么知道/他怎么盯的/一个温度细节）。
- 状态：CH002 R012 待修，R013 修（轻修，不破反派隐晦）。

## ERR-012 章｜女主感情线无"上风"实锤，全程收坦白

- 出处：CH002 R013（对容既白全程"接证据"，六刀里五刀被动接收；没问过一句能戳穿他认知错误的细节）
- 错误描述：她"主动落子"全在商战线，感情线是他在递、她在收；读者不觉得她掌控这段关系。
- 正确做法：感情线至少一次"她抛证据"——她知道他不知道的细节（亲眼/亲历），一句话让他的认知崩一角；上风靠细节立，不靠狠话。
- 状态：CH002 R013 待修，R014 修（"那份文件，你写的时候，我是睡着，还是醒着？"她"没有。那一晚的灯，我记得。你写到第三页，笔停了一下"——呼应上章"我醒着，还在问路"）。

## ERR-013 章｜慌乱后缺"收回掌控"节拍

- 出处：CH002 R013（背抵车门、衣摆被风吹向他之后，直接跳到他"我把自己也带来了"，她"别开眼"）
- 错误描述：身体先乱（退无可退/衣摆飘向他）之后没有"乱→收"的闭环，她一直处于被风吹着的状态。
- 正确做法：慌完必须立即收回——一个主动的、冷静的小动作（站直/整理/把东西放回原处），让读者看到她掌控回来。
- 状态：CH002 R013 待修，R014 修（"她站直，抬手把衣摆从风里拉回来，按平"）。

## ERR-014 章｜情感高潮区有句子、没镜头帧

- 出处：CH002 R013（"第七天，我就想去找你。第六年，我等到你自己回来"是全书最好的句子，但呈现只是"一行字引句"）
- 错误描述：金句立住了，画面没立住；读者记住句子，记不住"那一帧"（第一章有"两只手一热一凉"这种镜头级名场面，第二章没有同重量级画面）。
- 正确做法：情感高潮除台词外必须给一个镜头级细节（新旧痕迹/风里的颤抖/光的形状），让读者闭眼能看见那一帧。
- 状态：CH002 R013 待修，R014 修（"涂改过几回，最后一回的墨是新的；海风从窗缝灌进来，纸页在她手里抖了一下"）。

## ERR-015 章｜反派CP线结尾只有谜、没有温度回收

- 出处：CH002 R013（黎长聿结尾只有"他连她几点到南岬都知道"，之后无任何个人痕迹）
- 错误描述：热手男主（第一章名场面）在第二章结尾冷掉，读者对他的记忆只剩一条短信；三线（容/周/黎）失衡。
- 正确做法：反派CP线每章结尾至少回收一个温度帧（他握过她的细节/他盯过的痕迹），隐晦但不冷场。
- 状态：CH002 R013 待修，R014 修（"她忽然想起宴厅门口，他握住她手腕时，拇指压在她手背那道血痕上，她没动，他也只停了一下"）。

## ERR-016 章｜配角CP线单帧不足，六年没有重量

- 出处：CH002 R013（周妄生"我以为你死了"说完即被拒卡淹没，递的卡没有"准备了多久"的信息）
- 错误描述：配角CP出场即工具人——事件给了，重量没给；读者记不住他这六年。
- 正确做法：配角CP线至少一句"他的六年"（准备多久/藏了什么/哪年等的），一句话立住一个人的时间厚度。
- 状态：CH002 R013 待修，R014 修（"这张卡，六年前我就准备好了。只是没等到你活着"）。
