# 第二项｜城市核心定位：不是“机场＋工厂”，而是大规模实体产业进入全球市场的组织器

状态：`D-SE_GATEWAY_CORE_STRONG_CANDIDATE`

## 2.1 第一辨识度

岭州的第一辨识度建议定为：

> **把巨大制造腹地、订单、会展、航空客货、区域交通、外贸服务与全球供应链组织在一起的南方综合门户。**

它的强项不是单一技术突破，也不是单一海港吞吐量，而是把“生产—采购—展示—成交—报关—运输—交付—售后”压缩进高密度城市网络。

## 2.2 核心功能组合

第一版强候选功能包括：

- 出口制造和区域制造总部；
- 大型综合会展、采购与订单撮合；
- 国际航空客货与高价值物流；
- 跨境电商、外贸服务、货代、保险、合规与供应链金融；
- 汽车/智能装备/电子/耐用消费品等实体产业的总部、研发协同与专业服务；
- 全国公路、铁路、航空与周边港群之间的多式联运组织；
- 面向全球买家、供应商、代理商和专业服务机构的长期商业网络。

## 2.3 岭州的“快”与临洲不同

临洲的快，是产品、技术、融资和公司迭代快；岭州的快，是订单、打样、产能、物流和交付链条反应快。

因此：

- 临洲关心“这项技术能不能长成下一代产业”；
- 岭州关心“几十万件货怎么按时、合规、可追责地做出来并交给全球客户”。

## 2.4 不允许垄断全国实体经济

岭州可以是第一梯队实体经济门户，但不能被写成：

- 全国所有制造业总部所在地；
- 华夏唯一出口口岸；
- 全国最大港口、最大机场、最大会展、最大制造基地全部重叠的一座万能城市；
- 一座城市就能替代整个东南制造带和港群。

# 第三项｜相对地理与南方双核心：临洲做创新，岭州做大规模实体交付

状态：`SOUTHERN_DUAL_CORE_CANDIDATE / PORT_CLUSTER_SEPARATION`

## 3.1 相对地理

第一版只锁宏观方向：

- 位于华夏南部/东南向大型经济带；
- 背靠高密度制造腹地，连接沿海港群与内陆产业城市；
- 是海陆空综合交通的组织节点，但不等于“城区直接包住所有深水港”；
- 与临洲处于同一南方经济大区的高频互动范围，但不是同城、不是行政一体化。

## 3.2 临洲—岭州双核心

两座城市共同构成南方高强度经济带，但功能顺序不同：

- **临洲**：科技创新、技术商业化、创业资本、数字产业；
- **岭州**：制造腹地、外贸、会展、航空客货、供应链组织和实体交付。

高频合作场景可以包括：

`临洲技术团队 → 岭州试制/量产组织 → 周边产业城市制造 → 岭州会展/航空货运/贸易服务 → 全球市场`

反向也成立：

`岭州客户/订单反馈 → 临洲产品迭代与技术公司 → 岭州供应链重新组织`。

## 3.3 与南岬严格分工

岭州不能吞掉南岬：

- **南岬**是曜京体系内的全球商业港、港航制度和首都圈口岸节点，重点在港口、航运、保税、海事、边检、海关等多制度叠加；
- **岭州**是南方制造—贸易—航空—会展—供应链综合门户，更强调广大制造腹地和商业履约网络。

因此即便岭州周边存在重要港群，也不能复制“南岬式首都临港制度节点”。

## 3.4 与朔原候选功能分工

朔原偏先进制造、航空航天、材料、高可靠工业体系；岭州偏大规模民用制造、国际贸易和全球交付网络。

“岭州有机场”不等于“岭州承担北方航空航天制造主功能”。

# 第四项｜制造—贸易—会展—供应链生态第一版

状态：`ENTITY_ECONOMY_ECOSYSTEM_V1 / CANDIDATE`

## 4.1 制造腹地不是城市CBD里的巨大工业园

岭州的制造优势应采用“核心都会＋周边产业城市＋专门化园区＋交通走廊”的网络结构。

核心城区更适合承载：

- 区域总部；
- 产品与供应链管理；
- 外贸服务；
- 会展与采购；
- 设计、工程、质量、认证、法务与金融；
- 高价值小批量试制和展示。

大规模工厂、重型设备制造和高土地占用产业可以分布在周边独立产业城市或走廊节点，不必全部塞进主城区。

## 4.2 六类关键商业链条

第一版建议长期保留六类链条：

1. **订单链**：品牌商、采购商、渠道商、跨境平台和大型买家；
2. **制造链**：主机厂、零部件厂、代工厂、材料商和设备商；
3. **质量链**：检测、认证、质量追溯、召回和产品责任；
4. **贸易链**：合同、结算、信用证/贸易融资、税务、关务与制裁/出口控制合规；
5. **物流链**：航空货运、铁路、公路、仓储、冷链、货代和周边海港；
6. **售后链**：海外维修、退换货、备件、保险与争议解决。

这意味着一次“供应链危机”可以同时涉及合同、物理货物、数据、资金和声誉，不能靠某个男主打一通电话解决。

## 4.3 会展不是装饰背景

岭州的大型会展应具备真实生产功能：

- 新品与供应商集中展示；
- 大型采购季；
- 行业价格与订单预期形成；
- 海内外买家与地方制造网络高密度见面；
- 媒体、资本、监管和专业服务同时出现。

因此会展期可以成为多人物高密度交汇的合理场景，但不能自动让军警、医疗、情报等无关职业角色无理由聚集。

## 4.4 航空枢纽的正确使用

世界级航空枢纽能够提高：

- 国际商务人员到达频率；
- 高价值货物与紧急部件运输速度；
- 会展与商务流量；
- 跨境供应链的时间敏感度。

但机场不能：

- 取消海关、边检、安检和航权；
- 让人物随时调用航班或货机；
- 替代海运处理低时效大宗货物；

# 第六项｜交通门户与全国联系：世界级航空枢纽不等于人物拥有机场

状态：`TRANSPORT_ROLE_CANDIDATE / AVIATION_ANCHOR_RESPECTED / NATIONAL_BANDS_COMPATIBLE`

## 6.1 四类交通能力分账

岭州的交通优势必须拆成四条不同能力，不能写成一个模糊的“交通很强”：

1. **国际航空客运**：承接高密度商务、会展、采购、区域总部和跨国团队流动；
2. **国际航空货运**：适合高价值、时效敏感、体积相对可控的电子零部件、样品、备件、医药/冷链和紧急工业部件；
3. **全国铁路/公路网络**：连接岭州市域、周边制造城市、内陆供应商和南方经济带，是大规模实体货流的基本骨架；
4. **周边港群接口**：承担海运、大宗与低时效高体量货流，但港口可分布于周边独立法域，不能因为岭州组织贸易就把所有港口写成“岭州市港区”。

世界级航空枢纽提高的是**可达性和高价值物流能力**，不是城市或人物的无限运输权。

## 6.2 作者级门到门时间

继续服从全国V1，不另造更快时间：

- **曜京—岭州**：航空优先，门到门约5—8小时级，通常按半天至一天成本处理；
- **沧海—岭州**：高铁/航空约4—6小时级，是高频市场—实体产业商务轴，但不能无损当天多次横跳；
- **临洲—岭州**：维持数小时级高频协同，不锁精确分钟；足够近到形成双核心产业链，足够远到保留独立城市、法域和日程成本；
- **岭州核心城—周边制造/仓储/港口节点**：按一小时至数小时级二次转场理解，具体距离继续OPEN；“到岭州”不能自动等于“到工厂/港区/仓库”。

## 6.3 人、货、文件、数据、许可五流分离

岭州剧情尤其需要避免“航班落地=供应链恢复”：

- 人可以先到，货还在另一城市或口岸；
- 货已到机场，报关/检验/仓储/最后一公里仍可能未完成；
- 原产地、质量、保险、提单、检验证书等文件可能存在缺口；
- 供应链数据可能在平台里可见，但不等于可以合法读取全部商业秘密；
- 航权、海关、边检、检验、危险品、出口控制和特殊货物许可必须分别成立。

因此岭州交通的剧情价值是：**把全球连接压缩得很紧，但仍让现实制度和物理货流制造可计算的迟滞。**

# 第七项｜行政与都会区模型：核心城市负责组织，不吞并整个制造腹地

状态：`ADMIN_METRO_MODEL_CANDIDATE / FORMAL_RANK_OPEN / MULTI_JURISDICTION_REQUIRED`

## 7.1 首选空间模型

岭州建议采用：

> **一座法定核心城市 + 市域多中心 + 周边独立制造城市/县域节点 + 独立港口/物流节点，共同组成高强度产业都会区和经济走廊。**

这能同时解释：

- 为什么岭州能够组织巨大制造与贸易网络；
- 为什么大规模工厂、港口和仓储不必全部在主城区；
- 为什么“岭州项目”可能跨多个法定辖区；
- 为什么地方审批、税务、环保、劳动、公安、法院、港口与机场管理不能由一个城市部门全包。

## 7.2 都会区不是第二层政府

“岭州都会区”“D-SE经济带”“南方双核心”都只能表示经济/交通/产业联系，不自动产生凌驾法定政府之上的超行政机构。

跨城供应链项目必须承认：

- 工厂所在地管土地、环保、劳动与地方税务；
- 机场按民航、边检、海关和机场运营规则运行；
- 周边海港按各自港口、海事、海关/边检与地方制度运行；
- 跨市争议仍需确认合同、法院/仲裁、行政与执法权限。

## 7.3 继续OPEN的行政字段

本轮不锁：

- 岭州精确行政级别和省级归属；
- 法定辖区数量与名称；
- 周边产业城市、港口城市的正式名称；
- 自贸区、保税区、经开区等正式法源与名称；
- 都会区人口、面积和行政边界。

一句话：

> **岭州的强来自网络组织能力，不来自把周边所有节点行政吞并。**

# 第八项｜内部功能区：先锁八类长期场景，不急着制造一串区名

状态：`URBAN_FUNCTION_LAYERS_V1_CANDIDATE / NO_FORMAL_DISTRICT_NAMES`

## 8.1 八类可复用功能层

岭州首轮内部空间固定为八类长期场景层：

1. **国际航空与机场经济接口**：旅客、货运、会展客流、高价值物流、酒店和商务服务密集，但机场控制区权限严格；
2. **会展—采购—贸易核心**：大型行业展会、采购季、品牌发布、订单撮合与国际买家密集出现；
3. **区域总部与专业服务中心**：制造/贸易集团总部、供应链管理、法务、审计、保险、贸易金融、质量与认证机构；
4. **成熟老城商业生活区**：传统商业、学校、医院、老住宅、地方餐饮与长期商贸关系，避免岭州只有新CBD；
5. **试制—质量—工程接口带**：样品、工程验证、小批试制、检测认证及与周边工厂的技术接口；
6. **物流—仓储—分拨带**：仓储、冷链、货代、公路货运、铁路货站和跨境电商履约等高强度物理物流空间；
7. **普通居住与产业通勤区**：承载技术工人、采购、外贸、物流、服务业、家庭与大量跨区通勤；
8. **旧工业/滨水更新与公共活动空间**：承载城市历史、普通休闲、文化消费和工业转型，不把整座岭州写成纯工作机器。

这些是**功能层**，不是法定区县清单。

## 8.2 场景调用原则

- 需要“订单和人群高密度碰撞”时优先会展—采购核心；
- 需要“合同已经签了但货还没走”时优先物流/仓储/机场货运接口；
- 需要“资本和供应链真实碰撞”时进入总部—专业服务层；
- 需要“城市普通生活”时必须离开机场/会展/CBD，进入老城与居住通勤层；
- 需要制造现场时，优先转入周边独立产业节点，而不是默认市中心楼下就是工厂。

## 8.3 命名控制

本批不新增正式街区、机场、港口、会展中心或产业园名称。只有某个场景需要跨多卷反复复用并形成不可替代记忆点时，才进入单独命名裁决。
