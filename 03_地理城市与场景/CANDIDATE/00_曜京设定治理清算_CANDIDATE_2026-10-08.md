# 一、第一步｜第1—118项盘点

## 1.1 第1—8项｜城市母骨架

包含：城市母地图、历史形成史、城六区行政结构、道路/交通骨架、轨道交通、水系与滨水、城市中心等级、六区逐区深化。

治理判断：
- **结构价值极高**，构成曜京专项CURRENT未来的主体来源。
- 其中“多中心、旧核心与现代扩张并存、功能中心与行政区不等同、制度/商业/知识/工业/港航各有中心”等原则与现有上位CURRENT高度兼容。
- 城六区名称、面积、人口、边界、街道数量、具体河名、环线、铁路站与轨道线等目前仍属于聊天候选，尚未获得专项CURRENT权。

## 1.2 第9—18项｜人口—住房—治理—产业—公共服务—商业—安全—南岬接口—通河

治理判断：
- 城市社会学和制度边界大部分与曜京圈层CURRENT、国际环境CURRENT一致，可作为强候选。
- “国家治理≠市级治理≠区级治理”“专业权力不可跨域万能”“顶层优势主要体现为接口、信息、信用与时间”等应优先保留。
- 通河副中心、曜京—南岬具体连接、第二机场等具体地理/行政内容仍需单独裁决。

## 1.3 第19—38项｜新城、更新、普通生活、阶层心理、人物城市地图、气候、物流、教育医疗媒体文化、都会圈

## 1.4 第39—58项｜能源、水务、垃圾、食品、劳动力、财政、规划、建筑、国际人口、公益、灰色经济、旅游、无障碍、生态、维护、城市记忆

- 精确税制、规划机构、设施数量、人口占比等不得自动锁值。

## 1.5 第59—78项｜地址、命名、通勤、汽车、公交、铁路、机场、支付、保险、租赁、教育竞争、社区、隐私

治理判断：
- 大部分属于可长期调用的城市现实规则。
- “地址/地名源于历史自然地理”“距离以时间/换乘而非公里理解”“公共数据分权限、不可十分钟查完人生”等与现行项目硬边界高度兼容。
- 双机场、六大铁路枢纽等精确体系仍为候选。

## 1.6 第79—98项｜通信、快递、政务、药品、监管、企业、税务、不动产、大学、亚文化、体育、婚庆、家庭服务、私人安保、社会救助、宠物、噪音

治理判断：
- 主要属于生活/制度纹理，整体可保留为强候选或正文调用规则。

## 1.7 第99—118项｜叙事运行层

包含：场景六维坐标、地点选择、人物移动时间、偶遇概率、生活三角、权限地理、曝光等级、信息扩散、地点复用、24小时/星期/季节节律、天气影响、声景/气味、阶层信号、普通工作人员、团队移动、大型公共事件模型、正史连续性校验。

治理判断：
- 这20项不宜全部写成“曜京地理事实”，而应作为**曜京场景/叙事调用协议**的一部分。

结论：第1—118项并非118个等权正史条目，而是七层资产混合体：**城市静态骨架、行政候选、城市运行原则、社会结构、生活纹理、人物接口、叙事调用协议**。治理时必须拆层，禁止整包升格。

对聊天设定的影响：
- 可保留“曜京是全球级/全国级超级首都与多中心都市”。
- 必须避免把曜京写成全国所有产业、市场交易、港航、制造、科技、文化的绝对唯一第一中心。

## 2.2 与南岬CURRENT的关系

南岬现已正式拥有`REG_NANJIA`与专项CURRENT：
- 正式名称：曜京南岬临港新区。

因此聊天中下列旧状态已经失效：
- “南岬最新专项尚未读取/暂时冻结”。

下列聊天推演必须重新校准而不得直接沿用：
- “曜京内湾/南湾”作为南岬唯一上位湾体的设定；
- “南岬位于东南湾口”的精确坐标；

## 2.3 与东阜CURRENT的关系

东阜现已正式拥有`REG_DONGFU`与专项CURRENT：
- 正式工作名称：曜京东阜经济技术开发区。
- 父级：`REG_YAOJING`。

- 不得自动把东阜塞入“朝晖区”或“顺安”等聊天候选行政结构。
- 朝晖东/东北扩展、顺安机场走廊与东阜之间的行政/地理关系必须后续单独裁决。

同时LEGACY“雾港”已完成语义桥：
- 地点语义 → `REG_DONGFU`；
- 旧案/事故/真相等事件语义 → 继续作为LEGACY事件标签，等待EVT/FACT治理。

## 2.4 与曜京圈层势力CURRENT的关系

曜京圈层CURRENT已经正式建立：
- 同心层级＋九张主桌＋灰度通道；

- 城市空间不是势力领地；总部、执行地、证据/记录地可以分离；
- “总部在曜京”不等于“业务只在曜京”。

因此聊天中“西城=权力、朝晖=商业、青淀=知识”等可以保留为城市功能气质候选，但不能被写成某人物/家族对该区具有领地式控制。

# 三、第三步｜冲突分级清算

## 3.1 `UPSTREAM_LOCKED / 必须服从`

1. 曜京=华夏人民共和国首都、主叙事超级都市、`REG_YAOJING`。
2. 曜京高制度密度，各赛道正式权限分层，灰色空间不等于法外。
3. 南岬=`REG_NANJIA`，属于曜京；其半岛＋双湾＋岛链＋深水外港及六大空间区服从南岬CURRENT。
4. 东阜=`REG_DONGFU`，属于曜京东部—东北部产业体系；精确行政挂靠OPEN。
5. “雾港”地点语义解析到东阜；事件语义继续LEGACY，禁止机械全局替换。
6. 曜京不是全国所有领域唯一中心；跨域、跨赛道必须重算权限与成本。

## 3.2 `CURRENT_COMPATIBLE_STRONG_CANDIDATE / 建议下一阶段吸收`

1. 曜京采用**多中心、非同心圆、历史旧核＋现代扩张＋专业节点**结构。
2. 国家治理、城市治理、金融治理、市场资本、知识科研、制造物流、文化曝光分别拥有不同城市中心。
3. 东西城式旧核心承担历史/制度连续性；现代商务向东扩张；知识科研存在西北/北部强节点；南部与临港方向承担交通、制造和港航接口——具体行政名待裁决。
4. 城市空间必须保留普通居民、社区、学校、医院、市场和老旧住宅，不得全城精英化/摩天楼化。
5. “工作地、居住地、社交地、权力地不等同”。
6. 顶层优势体现为信息、接口、信用、专业团队和时间，而不是清空医院/道路/机场或跨部门万能权限。
7. 交通、住房、公共服务、产业、阶层和人口采用碎片化/网络化分布，不用“内城富、外城穷”简单划分。
8. 地址/地名优先来源于历史门、河、桥、村、驿、山、工业设施等，现代品牌名只在较低层级使用。
9. 99—118项的移动时间、权限地理、曝光、信息扩散、地点复用和连续性校验作为曜京正文调用规则继续保留。

# 五、第四步｜曜京静态地理基线V1候选

状态标签：`STATIC_BASELINE_V1_PREFERRED / CANDIDATE / NOT_CANON`

本步只确定“城市整体怎样摆在同一张地图上”的稳定拓扑，不提前锁定精确公里数、面积、人口、法定边界、河名、轨道线名或机场位置。

## 5.1 总体空间结构

曜京建议采用以下母结构：

> **内陆旧核 + 东向/东北向现代扩张 + 西北知识生态带 + 南部/西南部交通制造带 + 东部产业节点 + 独立临港战略极。**

这不是同心圆，也不是一条从旧城直通海边的连续城市带。

具体含义：

1. **历史旧核**位于曜京传统内陆城市平原核心，承担国家象征、治理连续性、传统商业与长期城市记忆。
2. **现代商务扩张**主要向东推进，形成高密度市场资本、国际商务、传媒和现代居住带。
3. **知识科研轴**主要向西北—北部延伸，形成大学、科研、医学、技术产业与大设施外溢结构。
4. **南部—西南部**承担大型铁路、专业服务、成熟工业更新、新制造与大尺度城市扩张。
5. **东部—东北部**必须为`REG_DONGFU`保留独立成熟产业节点，不能被中心城区商务带吞并。
6. **南岬**作为`REG_NANJIA`保持独立临港功能极，与中心城属于同一曜京体系，但不要求成为城六区连续建成区的自然末端。

## 5.2 西部自然边界

继续保留聊天中“西部山地形成真实城市边缘”的结构判断，作为强候选：

- 中心城区西侧存在连续山地/山前地貌；
- 石门方向承担城市—山地过渡；
- 青淀西北部可以形成湿地/园林/山前科研生态组合；
- 西部不适合复制朝晖式无限高密扩张；
- 山地的精确名称、主峰、河谷和自然保护区范围继续`OPEN`。

该结构与曜京“不是全方向均匀摊大饼”的城市逻辑兼容。

## 5.3 北部与东北部

北部—东北部不设定为单一功能：

- 西北/北部偏知识、科研、大设施和新城外溢；
- 东北部偏国际航空、城市门户、先进产业和成熟工业体系；
- `REG_DONGFU`明确位于东部—东北部成熟工业与产业体系中；
- 顺安/第一国际机场等聊天内容只能作为候选节点，不能覆盖东阜既有CURRENT。

因此未来总图必须允许：
**青淀/长陵方向 ≠ 东阜方向 ≠ 顺安/机场方向。**

三者可以通过环线、快线和城市走廊连接，但不得压成一条“东北新区”。

## 5.4 东部

东部承担至少三种不同城市语义：

1. 中心城东向商务扩张；
2. 城市副中心候选；
3. 东阜成熟产业体系。

因此“朝晖→通河→东阜”不应被画成一条单轴等级链。

更合理的V1拓扑是：

- 朝晖：中心城区东向商务/国际生活扩张；
- 通河：东部综合城市副中心候选；
- 东阜：东部—东北部成熟产业功能节点；
- 三者存在交通和就业联系，但法定边界、相互邻接关系与谁包围谁继续`OPEN`。

## 5.5 南部与西南部

继续保留以下结构作为强候选：

- 槐台承担中心城向南的铁路、专业服务、成熟居民与旧工业更新接口；
- 临川承担更外围先进制造与工程产业化候选；
- “南部增长”不自动等于“通往南岬的唯一走廊”。

因此此前把槐台直接视为南岬前门的推演降级。

曜京中心城—南岬未来可以存在多套客货通道，但起点、经过区域和方向必须服从南岬专项与后续交通治理。

## 5.6 南岬在曜京母图中的嵌入方式

正式采用“**父级归属明确、精确坐标暂不补值**”的处理：

- `REG_NANJIA`的父级固定为`REG_YAOJING`；
- 南岬自身的“半岛主陆＋双湾＋岛链＋深水外港”完整保留；
- 南岬不是城六区之一，也不自动是某中心城区的下辖片区；
- 南岬与曜京核心城市之间存在国家级客运、货运、物流、专业服务和制度联系，这是结构性必需；
- 但“南岬在旧城正南/东南多少公里”“必经哪一区”“双湾与曜京哪条河相接”等继续`OPEN`。

V1作者工作句：

> **曜京的城市核心在内陆形成，南岬把这座首都的制度与产业网络延伸到海上；二者强连接，但不是一片连续街区。**

## 5.7 东阜在曜京母图中的嵌入方式

`REG_DONGFU`在V1中采用“**独立功能节点、行政挂靠开放**”：

- 必须出现在曜京总图；
- 位于东部—东北部成熟产业体系；
- 与朝晖现代商务、顺安候选航空门户和通河候选副中心都存在经济/交通接口；
- 不自动隶属任何一个聊天候选城区；
- 不承担国际深水港语义；
- 不得因“雾港”旧称而被写成雾气弥漫、法外、偏远、港口化区域。

V1作者工作句：

> **东阜是曜京东侧的工业记录机器，不是曜京的海港。**

## 5.8 V1宏观拓扑结论

现阶段可以安全保留：

`西部山地约束`
→ `内陆历史核心`
→ `东向商务扩张`
→ `东部副中心/产业节点并存`
→ `北部科研与东北门户分叉`
→ `南部交通制造扩张`
→ `南岬独立临港战略极`

其中箭头只表示功能与发展联系，不代表严格直线方位或法定行政从属。

# 六、第五步｜行政区、功能区、规划节点四层关系定型

本步解决此前最容易混淆的问题：**一个名字究竟是行政区、功能区、城市副中心，还是社会地名。**

## 6.2 第二层｜法定行政区

`PREFERRED_STATUTORY_DISTRICT_CANDIDATE`

1. 东城区；
2. 西城区；
3. 朝晖区；
4. 青淀区；
5. 槐台区；
6. 石门区。

- 是否还有其他法定市辖区与其共同组成曜京市域。

## 6.3 第三层｜跨行政或特殊功能地域

已锁定的两个典型对象：

### A. 东阜
- 类型：经济技术开发/成熟产业功能地域；

- 可能与某法定行政区重叠、嵌套或跨界；
- 精确挂靠`OPEN`。

### B. 南岬
- 类型：战略临港新区；
- 已有`REG_NANJIA`；
- 属于曜京正常行政司法体系；
- “新区”不自动等同普通市辖区；
- 与传统行政区之间的精确法律结构由南岬专项继续管理。

由此确立一个长期原则：

> **项目中的`REG_*`是稳定地域节点，不等于每一个REG都必须对应同级法定行政区。**

这能避免把“经济技术开发区”“临港新区”“城市副中心”“行政区”全部混成同一种地图对象。

5. **槐台区**：由旧驿路、铁路、工业与南部城市扩张叠加形成的交通、专业服务、成熟居住与更新型城区。
6. **石门区**：由西部山口、资源工业和山前城市发展形成的中心城区西缘，是曜京最明确的城市—山地过渡区。

字段级锁定范围仅包括：
- 正式行政名称；
- 六者均属于曜京“中心城区/城六区”体系；
- 各自最核心的功能气质与相对方位。

继续保持OPEN：
- 精确面积、人口、边界；
- 街道/镇数量；
- 区政府精确驻地；
- 六区全部相邻关系；
- 六区是否需要分别注册V12 `REG_*`。

## 9.2 “城六区”术语正式定义

`城六区`在曜京专项语境中定义为：

> **曜京历史核心与连续中心建成区中，承担国家核心、传统城市生活、现代商务、知识科研、南部交通增长和西部山前过渡的六个法定中心城区的统称。**

它不是：
- 曜京全部行政区的总称；
- 财富等级标签；
- 权力等级标签；
- 六个功能纯化区。

因此“城六区”可进入曜京专项CURRENT，但不得推导“曜京只有六个行政区”。

## 9.3 通河法定身份与副中心身份同时硬锁

通河从`PLANNING_NODE_PREFERRED_CANDIDATE`提升为：

`LOCKED_FOR_YAOJING_SPECIALTY_CURRENT`

正式采用：
- **法定行政名称：通河区**；
- **规划/功能身份：曜京城市副中心**；
- “通河区”大于“城市副中心重点规划范围”；
- 城市副中心是市级治理、公共文化、综合商务、居住和交通共同发展的完整城市节点，不是第二国家政治核心。

同时锁定：
- 曜京市级行政职能可有相当部分向通河布局；
- 国家核心政治与国家级制度象征不因此从东西城整体迁出；
- 通河必须拥有就业、医疗、教育、文化和住宅的完整生活体系，不能成为纯行政城或纯睡城。

继续OPEN：

- 市级机构具体迁入清单；
- 通河是否现在就需要V12独立`REG_*`；
- 与东阜的精确行政接壤关系。

## 9.4 六区＋通河之间的相对结构

首版专项CURRENT只锁以下低风险关系：

- 东城、西城构成历史旧核的两翼；
- 朝晖位于中心城东向现代扩张主方向；
- 青淀位于中心城西北—北部知识科研主方向；
- 槐台位于中心城南部—西南部交通与增长主方向；
- 石门位于中心城西部山前边界；
- 通河位于曜京东部，承担唯一综合城市副中心功能。

不在首版专项CURRENT锁死所有两两边界。

## 9.5 东阜、南岬不被并入“城六区＋通河”
