# 16_自动化与校验工具｜放置说明

- 放什么：可一键运行的校验脚本（只读，不做任何修改/删除）。
- 建议文件：
  - `硬规则校验器.py`：字数 / 中文引号配对 / ASCII 引号 / 破折号 / 禁字 / 段落纪律 / 段首代词。
  - `一致性回归检查.py`：正文中未注册实体告警 + 快照"严禁事项"提前泄露告警。
  - `资产核对.py`：MANIFEST 清单 vs 实际文件核对。
- 运行方式：
  - `python 硬规则校验器.py 正文文件.md [--config 配置]`
  - `python 一致性回归检查.py --body 正文文件 --registry 01_实体图谱.csv --forbidden 严禁词表`
  - `python 资产核对.py --manifest 00_项目资产清单_MANIFEST.md`
- 铁律：
  - 脚本只输出证据，不替代 QA 五视角的文学判断；"技术通过"不冒称"读者心动"。
  - 校验结果登记进 `CHUID_XXXX_修改过程记录.md` 的"验证结果"节。
- 依赖：python 3.8+，仅标准库。
