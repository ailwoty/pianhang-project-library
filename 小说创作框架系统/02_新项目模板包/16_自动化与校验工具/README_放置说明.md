# 校验工具｜FRAME_R5

用途：只读核验定义清楚的结构/词面错误；不评文学质量，不计算爆款概率。Python 3.8+，仅标准库。

- `框架体检.py --root .`：规模算术、配置、12维定义、核心资产、空模板状态。
- `硬规则校验器.py 正文.md --config 15_数据资产与机器可读/项目配置.json`：标记内字数、引号顺序嵌套、禁词精确例外、破折号可配置、空行分段与连续短段、段首代词。
- `一致性回归检查.py --body 正文目录 --registry 15_数据资产与机器可读/01_实体图谱.csv`：已注册名出场与配置禁词；不声称识别所有未知人名和语义越界。
- `资产核对.py --manifest 00_项目资产清单_MANIFEST.md`：所有文本/代码/JSON/HTML等精确路径；缺项、漏登、重复均失败，实际模板文件名含【】也须检查。
- `python -m unittest discover -s 16_自动化与校验工具/tests -v`：坏例必须被拦，空输入不能PASS。

正文用独占一行的BODY_START/BODY_END HTML注释界定，标题和记录在标记外。旧格式可显式`--allow-unmarked`，报告标注全文口径，不能冒称只统计正文。
退出码：0已检查范围通过；1规则失败；2输入/配置错误。无正文、空注册表、乱码、错误配置不静默通过。工具不覆盖人称深层语义、因果、人物动机、读者心动或完整版权审核。
