# 【书名】｜任务前置执行指令

状态：ACTIVE / FRAME_R5 / 2026-10-21

用途：【书名】｜任务前置执行指令。本轮为证据化质量升级；用于新项目配置与验收，不新增《偏航》剧情事实。
依赖：项目配置、作者设计说明、章节合同与质量证据。使用：按本页步骤产出表中记录，再进入下一关。

## 现行依据与权限

作者最新明确指令 → 本书锁定宪法 → 唯一设定母版 → 章节合同 → 运行态已发生事实。框架规则只管生产与验收，不覆盖本书作者决定。常规可逆修复在已授权范围内继续；只有互斥的作者选择、改动既定结局等无法推定的事项才提出裁决，不因普通执行细节停机。

数值唯一来源为 `15_数据资产与机器可读/项目配置.json`。默认新书五卷、每卷20章、全书100章，目标均字3000，总计300000；章长允许2700—3300。此为本框架内部起始配置，非番茄官方章长规定。CP默认1条，节点数待配置；全勤不是通用硬规则。复制模板不得把本书《偏航》的132章/17线带入新书。

## 写前五查（不能以搜索命中代替全文读取）

1. 入口、作者指令、配置、宪法、适用错误清单；说明本轮实际读取文件及版本。
2. 上一章定稿全文和修改记录；首章用T0起点替代，不伪造上章。
3. 本章合同、对应人物主档、关系与知情账；涉及设定的母版、场景、机制源文件。
4. 正文索引、快照、事务日志；区分草稿、待审、定稿、已发布。草稿不推进正式世界时钟。
5. 列本章目标、阻力、选择、代价、状态变化、兑现和章尾期待；默认核心角色≤3、主冲突1、强钩子1、新概念≤1。群像高潮如需例外须写入合同并核验可读性。

加载包可集中呈现来源全文与相关条款，但须登记源路径、内容哈希、读取日期；来源变更则失效。不得承诺所有任务永远只读五六个文件。

## 单章流水线

先建修改记录 → 读写前清单 → 合同与场景卡 → 起草R001 → 机器检查 → 八轮内容检查 → 冻结版本评审 → 修改新R号 → 定稿事务 → 回归。

八轮为：因果与信息、人物欲望、关系变化、期待兑现、节奏与缓冲、语言声纹、重复与模板腔、整体复核。每轮输出缺陷位置与修复，不用八个“通过”代替检查。优先修阻断和大缺陷；允许返修，禁止为了9.9刷分反复改坏已成立的段落。

## 文本契约

正文以独占一行的 `<!-- BODY_START -->` 与 `<!-- BODY_END -->` 包围；标题、元数据、记录放标记外。字数=正文Unicode字符数去空白，含标点。与平台后台计字不一致时记录两者，不混称。
段落按空行分隔，软换行归同段。引号须按顺序和嵌套配对；专名禁字例外只允许配置中的准确词。破折号、段首代词、字数和短段规则按JSON选择，不把某一书口味强加所有题材。动作、心理、外貌只写有意义的变化，不给每句台词机械加小动作。

## 状态与事务

PLANNED → DRAFT → SUBMITTED → FINAL → PUBLISHED；旧版SUPERSEDED。模板实例必须从0定稿开始，示例行不算已发生。
定稿必须同步正文索引、状态快照、事务日志、修改记录及章节进度CSV（五处）。同一事务携带chapter_uid、revision、body_sha256、pre_state、post_state；已定稿不得静默覆盖。
正文文件保留每版；Git提交保存框架旧版本，升级报告记录父提交，可通过新提交恢复，无须复制第二份活动母版。上传比较远端HEAD，保留并发更新，不强推。
