- 当前进度：【CH001 已定稿 / CH002 待评审 / 其余为计划】

## 四、章节要素预算（硬规则，每章动笔前列清单）

1. 核心角色 ≤ 3（含女主；其余角色不出场或仅作无台词背景）
2. 核心冲突 ≤ 1（一章只打一个主冲突，其余推后）
3. 新钩子 ≤ 1（章末一个强钩子，中段不埋新悬念线）
4. 新概念 ≤ 1（新地名/术语/人物一章最多一个，且带半句可懂解释）
5. 等量交换纪律：每加一个要素，必须删一个同等要素
6. 裁决顺序：讲明白优先于爆点密度（要素预算管内容量，不冲突）
7. 章节合同"要素预算清单"为本章必出现/严禁出现的最高依据

## 五、文字硬规则（按本项目定制，示例）

- 引号一律中文：“”双引、内嵌‘’单引，禁英文直引号（生成后校验清零）
- 禁破折号（—— / — / -- / –），替代用逗号、括号、冒号或拆句
- 禁字表：【如 衡/聆/宁/常/邵 等易串戏字】，专名例外
- 人称规范：【如：每段第一个指代用全名；禁单字"X"指代女主】
- 字数区间：单章 2500—3200 字（含标点、不含元数据；默认均值 2800，按题材包配置调整）
- 段落纪律：一般叙述段 30—80 字、单段上限 150 字；对话独立成段；不连续三段均 <40 字或均 >65 字
- 专有代号首次出现必须当场白话解释
