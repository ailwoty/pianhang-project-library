## 本质定义（作者亲定，逐条填写）

### ① 这是一本言情小说

【填写：一切设定（事件/权谋/系统/逻辑）都为人物与爱情服务，不让设定吞掉爱情。】

### ② 爽文设定成立、情感拉扯成立

【填写：任何剧情可以保证不合理，但这两条必须成立。】

### ③ 爱情线占正文约 XX%

【填写：爱情占比与事件占比；事件线存在的唯一意义是推动爱情。】

### ④ 事件逻辑满足读者内心的疯狂

【填写：越疯越痛越爽越爱越正确；现实"讲得通"排在"内心疯狂"之后。】

### ⑤ 全部服务于 N 位主角的爱情纠葛

【填写：女主与每一位 CP 都有浓烈完整的爱情线，无"某位浓烈其余清淡"之分。】

### ⑥ 必须有 Boss 链 / 事件受益链

【填写：大Boss/小Boss/受益者来自主角团与重要配角团，既是拉扯对象又是事件操盘者。】

### ⑦ 人人有阴暗面

【填写：恶意、疯狂、不合法的一面是爱情与打脸的燃料。】

### ⑧ 人人极端

【填写：极端性格、极端行事、极端选择，可以拿一切去赌爱情。】

### ⑨ 快节奏

【填写：压缩铺垫、提前引爆、加快打脸频率。】

### ⑩ CP 多线与详略

【填写：关系形态多样；每位 CP 有完整结局（HE/BE/开放式），不留未处理关系。】

### ⑪ 每段关系按"战场"设计

【填写：主要战场 2—4 个 + 次要战场 5—6 个；场景让位情感烈度，无需符合逻辑。】

### ⑫ 亲密/性关系是爱情核心引擎

【填写：亲密戏高频、多形态、直接推动关系转折；按平台合规与作者尺度落地。】

### ⑬ 读者终检

【填写：每章必须有钩子 + 至少一个大型打脸名场面 + 一段核心情感高潮。】

## 执行检验清单（每次写正文/改设定前必过）

| 检验项 | 通过标准 |
|---|---|
| 言情本质 | 本章核心是人物与爱情，设定没吞掉人物 |
| 爽+拉扯 | 爽文设定成立，情感拉扯成立 |
| 爱情占比 | 本章爱情/情感内容 ≥ 目标占比 |
| 内心疯狂 | 事件逻辑服务读者内心疯狂，而非现实合理 |
| N 主角 | 出场主角都有浓烈爱情线，无等级之分 |
| Boss链 | Boss/受益者来自主角团或重要配角团 |
| 阴暗面 | 人物有恶意/疯狂/不合法一面，作为爱情与打脸燃料 |
| 极端人格 | 人物极端性格、极端行事、极端选择 |
| 节奏 | 压缩铺垫、提前引爆、加快打脸频率 |
| CP 多线 | 爱情状态多样，详略由主战场决定，无未处理关系 |
| 战场设计 | 名场面/拉扯/博弈让位情感烈度 |
| 亲密引擎 | 亲密作为情感转折引擎，高频、多形态、推动剧情 |
| 读者终检 | 每章有钩子 + 打脸名场面 + 核心情感高潮 |
