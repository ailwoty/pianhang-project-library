1. 读根前置 → 唯一母版 → 核心事件档案 → N 条 CP 线 → 章节排场表 → 运行态账（快照/日志/关系/实体）→ 本章合同与启动包。
2. 读取本章出场人物的当前主档、地点、实际合同行；核对新事实与知情边界。
3. 生成正文（首稿 R001）→ 硬规则校验 → 八轮自查 → 修改过程记录 → 读者视角评审 → 定稿。
4. 按独立正文事务提交：同步正文索引 + 状态快照（世界时钟游标）+ 事务日志 + 修改记录，四处一致才算完成。
5. 当前章节目标字数：【如 2500—3200 均值 2800】；整章流程服从根前置，不中途跳步。
