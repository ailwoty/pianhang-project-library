## 文件使用说明

- 用途：为每个正文候选提供独立、可追溯的质量裁决流程，具有质量放行否决权。
- 内容边界：只规定文学质量/事实一致性/读者体验审核流程，不新增故事事实；不替代正文事务提交。
- 关系：根级八轮自查继续生效且不能被本文件替代；报告格式按审核工单模板。

---

## 一、五视角审稿（同一章必须同时经得住五个视角）

1. **正史审计员**：事实、时间、地理、职位权限、关系权限、知情边界一致；不靠想象修补未知项。
2. **人物敌对审稿人**：找出任何人物变成剧情工具、临时降智、违背底层欲望、失去真实自利的地方。
3. **读者体验审稿人**：能否建立期待、获得兑现、承受变化、持续追读；强情绪不等于情绪有效。
4. **语言审稿人**：逐句检查硬规则与真实声音；指出 AI 腔、同质化、无效描写、可预判模板。
5. **社会后果审稿人**：高位人物行动对普通人/机构秩序的可见回声是否按场景需要出现。

同一模型执行也必须先冻结作者稿、输出具体证据，不能以"我已自查通过"替代独立审核。

## 二、成稿检查（十四项，每项必须有正文证据）

| 检查项 | 必须回答的问题 |
|---|---|
| 专名 | 首次涉及机构/人物是否用正确名称并说明身份 |
| 地点 | 读者能否定位场景、行动空间、行政归属 |
| 环境 | 光线/声音/温度/材质是否有读感或行动功能 |
| 生活质感 | 是否让人感到舒适、乐趣、审美、诱惑与代价 |
| 主角魅力 | 是否有独有审美、主动性、机敏、互动或吸引力 |
| 主角危险感 | 判断/选择/筹码是否使局势可能改变 |
| 语气与幽默 | 是否易懂鲜活，俏皮来自人物或当场反差 |
| 主线与因果 | 动作为何发生、造成什么新条件、如何连章合同 |
| 心理与行为 | 情绪/想法/动作/后果连贯且符合人物指纹 |
| 高潮与爽点 | 铺垫、反击、结果、余波是否实际兑现 |
| 节奏 | 信息/行动/回报/缓冲比例是否适合当前阶段 |
| 信息差 | 谁知道/从哪知道/何时知道，读者与人物是否分层 |
| 生活与宏大尺度 | 私人生活有滋味，大场面有主体/空间/行动/后果 |
| 连续性 | 前章遗留的情绪、关系、事实、代价是否继续有效 |

## 三、审核级别

- SEGMENT_QA：单个约 500 字已确认片段（局部规则/衔接/信息边界）
- CHAPTER_QA：整章候选（结构/节奏/承诺兑现/首尾钩子）
- ARC_QA：连续 3—10 章（重复情绪/无成长失败/时间债/多线差异）
- VOLUME_QA：每卷复核（人物弧线/信息释放/长期承诺回收）
- POST_COMMIT_AUDIT：已定稿章只读审计，产生修订申请不自行修改

## 四、硬门槛

1. 硬规则校验不过（字数/引号/破折号/禁字/段落）不进入文学审核。
2. 适用项没有证据不得通过；非本题材要求（如宏大尺度/危险感）可写N/A并说明，但因果/人物选择/兑现不可豁免；存在P0/P1先返修，不以禁词/字数/总分抵销。
3. 审核通过不绕过正文事务提交（索引/快照/日志/记录四同步）。
