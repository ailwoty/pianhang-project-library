# 21_01｜对标拆解工作流

状态：ACTIVE / 开书前必做
用途：把番茄头部同题材作品拆成结构数据，让"爆款长什么样"从感觉变成清单。

## 一、选对标（3 本）

1. **天花板对标**：同题材番茄 TOP50 内最爆的一本（看它吃满题材红利的样子）
2. **同期对标**：近 3 个月新起量、同题材的（看现在的市场口味）
3. **反面对标**：同题材扑街或高开低走的一本（看读者弃在哪）

获取：番茄热榜/新书榜/飙升榜 + 评论区。

## 三、拆解 → 行动（三项产出）

1. **可抄清单**：书名公式、钩子类型、节奏配置 → 进题材包
2. **差异化清单**：天花板对标没做好的点 / 读者抱怨点 → 你的机会点，写进母版
3. **红线清单**：反面对标弃书原因 → 进错误禁令清单，开篇先避

## 四、拆解纪律

- 抄机制不抄情节（防洗稿，也防失去辨识度）
- 对标数据是"参考系"，不是"复刻目标"；你的书必须有至少 1 个差异化卖点
- 拆解结果登记进 `02_数据回流登记表`，写回题材包
