# 21_04｜首秀 7 天观测协议

状态：ACTIVE / 上架首周执行
用途：首秀数据出来后 7 天内做对三件事：判断、调整、决策（加码/快改/止损）。

## 一、观测指标（每天记录）

| 指标 | 怎么看 | 健康信号 |
|---|---|---|
| 首日流量/曝光 | 平台数据 | 有推荐池进入 |
| 前三章留存 | 读到第 3 章的比例 | 留存率 > 同类均值 |
| 章均追读 | 每章继续读比例 | 稳定或上升 |
| 评论/催更 | 读者行为 | 有情绪化评论（共鸣） |
| 收藏 | 拉新能力 | 稳定增长 |

## 二、7 天决策树

```
第 1—2 天：数据打底
  ├─ 有流量 + 留存好 → 全力更新，观察曲线
  ├─ 有流量 + 留存差 → 定位掉点章（第几章弃）→ 准备快改
  └─ 无流量 → 不慌，检查题材/标签/简介匹配，等 3 天复测

第 3—4 天：趋势判断
  ├─ 追读上升 → 加更，把高共鸣点复制到后续章
  ├─ 追读平 → 回看 19/10 掉点五大病灶，改钩子
  └─ 追读下降 → 找到掉点章，重写章尾钩子（一次手术级修改）

第 5—7 天：最终决策
  ├─ 数据达标（相对同类）→ 加码：存稿、稳定更新、热度雷达顺势
  ├─ 数据中下 → 快改一次 + 再观察 3 天；仍不行 → 止损
  └─ 止损决策 → 按 21/05 多书组合策略，资源转向下一本
```

## 三、止损规则（提前定好，避免情绪决策）

- 止损触发：7 天数据低于同类均值 50% 且无上升趋势。
- 止损 ≠ 烂尾：把已写章节归档，总结"这次数据告诉我们什么"进回流表。
- 止损后 48 小时内：不开新书，先复盘（20/02 回流登记）。

## 四、数据 → 规则回流

- 首秀验证有效的钩子/节奏 → 写回题材包
- 掉点原因 → 错误禁令清单
- 全部结论登记 `20/02 数据回流登记表`
