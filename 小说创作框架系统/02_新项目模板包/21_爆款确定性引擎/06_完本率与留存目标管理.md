# 全周期质量与结局履约

状态：ACTIVE / FRAME_R5 / 2026-10-21

用途：全周期质量与结局履约。本轮为证据化质量升级；用于新项目配置与验收，不新增《偏航》剧情事实。
依赖：项目配置、作者设计说明、章节合同与质量证据。使用：按本页步骤产出表中记录，再进入下一关。

章窗按总进度缩放，不把前三十章都叫拉新、三十章后才写感情。开篇就兑现本题材承诺，全程兼顾新读者理解和老读者回报。

| 时点 | 作品检查 | 结果证据 |
|---|---|---|
| 前三章 | 主角欲望、第一步与回报、阅读理由 | 冻结正文与试读 |
| 每5章 | 连续性、重复手段、已到期承诺 | 运行账与人工回归 |
| 每10章 | 小弧新条件、情感变化、产能 | 合同前后态与回顾 |
| 60%/80% | 主线与终局能否装入剩余字数 | 结局预算 |
| 末段 | 核心秘密、关系、选择与生活余波兑现 | 承诺账关闭证据 |
| 完结 | 兑现核心承诺，说明有意开放项 | 完结复盘 |

完本是创作完成状态；完读是读者行为指标，两者不混用。留存按22域定义，数据不可得时写NOT_TESTED。长线伏笔可跨卷，只要兑现窗明确，不以“超过一卷”机械判错。
