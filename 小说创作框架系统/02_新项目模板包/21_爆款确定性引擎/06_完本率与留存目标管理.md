# 21_06｜完本率与留存目标管理

状态：ACTIVE / 每本全周期
用途：把"留存质量"做成可管理的目标表，逐卷追踪，防止中途烂尾和后期掉点。

## 一、30 万字全周期目标表（参考值，按题材包调整）

| 阶段 | 章窗 | 关键目标 | 健康信号 |
|---|---|---|---|
| 拉新期 | CH001—030 | 黄金三章拉力 + 钩子密度最高 | 前三章留存 > 同类均值 |
| 留存期 | CH031—060 | 感情线深度顶上 + 主线每卷揭一层 | 追读稳定/微升 |
| 稳定期 | CH061—080 | 长线钩密集兑现 + 新钩续上 | 无连续掉点章 |
| 收束期 | CH081—100 | 主线回收 + 情绪收束 | 完读率不崩、无烂尾差评 |

## 二、逐卷留存检查（每卷末对照）

- [ ] 本卷追读曲线：稳定 / 上升 / 下降（下降定位到章）
- [ ] 本卷每 CP 有效出场（全勤保底）
- [ ] 本卷感情线前进 ≥1 个亲密节点
- [ ] 本卷主线释放一层（读者记得主线）
- [ ] 本卷末爆点成立（卷末必爆）
- [ ] 无未回收的长线钩遗留超过 1 卷

## 三、防烂尾三查（每 20 章）

1. 主线还剩多少没写？剩余章数能否装下？（不够就压缩支线）
2. 还有几个"承诺给读者但没兑现"的钩子？（超过 3 个就要排队回收）
3. 最近 10 章还有人在追吗？（数据为准，别自我安慰）

## 四、完本质量门（结局验收）

- [ ] 全部主线回收（核心事件真相、Boss 清算）
- [ ] 全部 CP 线有终局（HE/BE/开放式，无未处理关系）
- [ ] 最后 5 章无新开大坑
- [ ] 结局有"终局感"（读者不骂烂尾）
- [ ] 完结后按 18/01 复盘，结论回流框架
