# 爆款目标与证据边界

状态：ACTIVE / FRAME_R5 / 2026-10-21

用途：爆款目标与证据边界。本轮为证据化质量升级；用于新项目配置与验收，不新增《偏航》剧情事实。
依赖：项目配置、作者设计说明、章节合同与质量证据。使用：按本页步骤产出表中记录，再进入下一关。

旧目录名为兼容保留；“确定性”只指流程步骤可复现，不表示市场结果确定。

## 定义本书的成功

作者开书前填写：核心读者、观察期、可用后台指标、基准来源、最低可持续收益或读者目标、写作时长预算。没有这些定义，就不能事后移动“爆款”标准。

## 三层目标

框架：12维均有生产方法和验收证据，工具不漏掉已定义的阻断。作品：每维以9.9目标档打磨并披露未验证。市场：按成熟队列与实际发布结果验证，未知不写概率。
选题、开篇、人物、留存和传播相互影响；旧乘法式只可作比喻，没有校准数据不可计算“爆款率”。没有任何框架可确保100%爆款。

## 执行门

G0 定位与配置 → G1 开篇原型与试读 → G2 连续10章续航检查 → G3 发布准备 → G4 成熟数据回看 → G5 终局与复盘。
每关按缺陷与证据放行，不以单一主观8分替代条件；允许先写原型再验证，禁止“没三章不能开书、没开书不能写三章”的循环。
