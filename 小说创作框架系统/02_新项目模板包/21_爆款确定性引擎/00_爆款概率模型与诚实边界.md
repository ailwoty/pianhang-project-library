# 21_00｜爆款概率模型与诚实边界

状态：ACTIVE / 开书前必读
用途：把"想要 100% 爆款"翻译成可工程化的目标，管理不确定性，避免被"包爆"承诺收割。

## 一、爆款概率模型

```
爆款 = 题材匹配 × 开篇质量 × 留存质量 × 平台运气
         （选对赛道）  （黄金三章）  （追读/完读）  （算法与竞争）
```

- **前三项框架可控**：题材包 + 热度雷达管选题，黄金三章清单管开篇，追读清单 + 首秀协议管留存。
- **第四项不可控**：首秀流量、同期竞争、算法调整。任何框架都无法 100% 保证爆款。

## 二、工程目标（替代"100% 爆款"的可行表述）

1. **开书前**：可行性评分 ≥ 8 才开（21/02 评分卡），把"选错题材"从源头砍掉。
2. **首秀前**：黄金三章拉力测试全过（21/03），把"开篇劝退"砍掉。
3. **首秀后**：7 天观测协议（21/04），数据好就加码，数据差就快改或止损重开。
4. **长期**：多书组合（21/05），让"一本爆"的概率变成"组合里至少有一本起量"的概率。

## 三、概率提升的现实区间（行业常识参考）

- 方法得当 + 执行到位：首秀能起量（进入推荐池）的概率显著高于盲写。
- 起量 → 爆款仍有漏斗：题材天花板 × 留存 × 运气。框架的目标是**把漏斗每一级的转化做到位**，让爆款成为"大概率事件"，而不是"赌"。

## 四、防骗原则（对"包爆"话术的免疫力）

- 凡承诺"保证爆款/保证签约必火"的，一律视为无效信息。
- 唯一可信的验证是**你自己的数据**：追读曲线、完读率、评论共鸣（见 21/04 与 19/10）。
- 把"这次数据告诉我什么"当作每一次创作的回馈，而不是"这次没爆=失败"。

## 五、决策口诀

选对赛道 → 开篇拉满 → 留存顶住 → 数据说话 → 快改或止损 → 多书对冲。
