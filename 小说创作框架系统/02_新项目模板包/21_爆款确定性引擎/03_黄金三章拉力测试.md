# 21_03｜黄金三章拉力测试

状态：ACTIVE / 三章写完 R001 后必做
用途：在首秀之前，用"读者 3 秒划走"的标准给开篇做拉力体检。

## 一、自测划线法（对三章原文操作）

1. **3 秒测试**：把第一章前 300 字单独拿给 3 个不在场的试读（或自己隔一天再看），能复述"发生了什么+为什么想看下去"才算过。
2. **划线法**：通读三章，划出让你"想翻下一页"的每一处；第一章划线处 ≥3、三章合计 ≥8 才过。
3. **空白段测试**：把每一章结尾最后一句话遮住，问自己"如果这章结束在这里，我会追下一章吗？"——三章都要"会"。

## 二、钩子分类拉力（每章章尾钩子按类型打分）

| 钩型 | 拉力感 | 说明 |
|---|---|---|
| 情绪未落（委屈/愤怒/心动悬着） | 强 | 读者带着情绪追 |
| 真相将出（秘密逼近） | 强 | 读者想知道 |
| 新威胁/新情敌 | 中强 | 制造危机 |
| 反转/意外 | 中强 | 打破预期 |
| 平淡收尾（无未了情绪） | 弱 | 必须重写 |

三章章尾钩子任一为"弱"→ 重写章尾再测。

## 三、试读协议（有条件时）

- 找 1—3 名目标读者类型的人，只给三章，不问"好不好"，问三个问题：
  1. 你会在哪里停下来不看了？（定位弃点）
  2. 你最想看到后面发生什么？（验证钩子）
  3. 你会给朋友推荐吗，用一句话？（检验传播点）
- 弃点早于第三章 → 开篇重做；钩子无人提 → 钩子无效，换类型。
