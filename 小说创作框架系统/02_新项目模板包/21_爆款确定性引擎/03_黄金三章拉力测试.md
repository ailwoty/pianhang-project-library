# 前三章冻结试读与拉力测试

状态：ACTIVE / FRAME_R5 / 2026-10-21

用途：前三章冻结试读与拉力测试。本轮为证据化质量升级；用于新项目配置与验收，不新增《偏航》剧情事实。
依赖：项目配置、作者设计说明、章节合同与质量证据。使用：按本页步骤产出表中记录，再进入下一关。

先记录正文版本、哈希与题材承诺；可在G0后写三章原型，不必先获正式发布许可。

1. 不解释背景，让目标读者复述主角想要什么、阻碍是什么、第一步做了什么。记录原话与误解。
2. 允许随时停读，记录准确段落与原因。区分看不懂、不喜欢、与标签预期不符、现实中断。
3. 问“最想看后面哪件事”，与作者预设期待对比；不要问“是不是很爽”。
4. 问是否愿意自选继续，记录行为与口头评价的区别；不以划线数量充当留存。
5. 按一个主要假设改版，检查关键行动和回报是否真正变好。

招募、分组、指标与样本限制统一见22域。AI读者模拟、作者隔天重读、真人试读分别记录；前两者不能代替第三者。当前模板试读结果为NOT_TESTED。
