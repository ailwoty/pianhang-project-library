# 15_数据资产与机器可读｜放置说明

- 放什么：供脚本处理的结构化数据（CSV/JSON），与 md 双写同步。
- 建议文件：
  - `00_章节进度表.csv`：每章一行（章号/状态/字数/定稿日期/主导线/钩子回收），脚本统计进度用。
  - `01_实体图谱.csv`：全部注册实体（人物/组织/地点/事件），一致性回归检查用。
- 同步规则：
  - 章节定稿后同步更新进度表（与正文索引、状态快照、事务日志四同步之外的第 5 处）。
  - 实体新增/更名后同步图谱（与 `09_运行态与事务控制/02_实体注册表.md` 一致）。
- 口径：CSV 为"机器快照"，md 为"权威正文"；冲突时以 md 为准并立即修正 CSV。
- 编码：CSV 用 UTF-8 带 BOM（Excel 打开不乱码）。
