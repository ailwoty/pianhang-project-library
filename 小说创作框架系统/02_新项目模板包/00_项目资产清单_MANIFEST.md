## 七、登记原则与说明文件

- 本清单只登记**正式资产**（每章/按需/一次用资产 + 模板资产）；各目录的 README 放置说明类目录说明文件不逐一登记（由目录树管理），资产核对默认以 WARN 提示，`--strict` 才报错。
- 占位路径（含 `【】` 或 `XXXX`）由校验脚本自动跳过存在性检查。
- 通配路径（含 `*`）由校验脚本按 glob 校验。
