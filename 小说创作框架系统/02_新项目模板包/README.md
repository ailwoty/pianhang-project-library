## 快速开始

1. 新开对话 / 新协作者：先读 `00_入口与治理/00_总索引_CURRENT.md` + `README.md`。
2. 写正文：按 `00_入口与治理/04_任务前置执行指令_持续更新.md` 的单章流水线跑。
3. 校验：`python 16_自动化与校验工具/硬规则校验器.py <正文文件>`。
4. 变更：每次变更登记 `CHANGELOG.md`，文件增删同步 `00_项目资产清单_MANIFEST.md`。
