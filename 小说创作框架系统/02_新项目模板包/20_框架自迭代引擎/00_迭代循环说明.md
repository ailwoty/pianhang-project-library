# 20_框架自迭代引擎｜迭代循环说明

状态：ACTIVE / 框架进化的总机制

## 文件使用说明

- 用途：让"框架系统"和"在写的小说"双向进化：作品实战经验回流，更新题材包/宪法/梗库/清单，框架越用越强。
- 铁律：任何规则变更必须①登记 `03_框架版本历史.md` + 根 CHANGELOG ②更新后跑一次资产核对 ③写明"改动依据"（数据/复盘/作者指令），禁止无依据改动。

## 迭代循环（PDCA）

```
┌─ ① 写 ─ 单章流水线照常（每章）
├─ ② 评 ─ QA 五视角 + 读者视角评审（每章）
├─ ③ 测 ─ 追读/完读/评论数据回看（每 10 章）
├─ ④ 回 ─ 数据与复盘登记（每 10 章回顾 + 完结大复盘）
├─ ⑤ 改 ─ 更新题材包/宪法条款/梗库/追读清单（依据④）
└─ ⑥ 验 ─ 版本登记 + 资产核对 → 回到①
```

## 三个触发点

| 触发点 | 频率 | 做哪些事 | 产出 |
|---|---|---|---|
| 轻量回顾 | 每 10 章 | 追读数据回看 + 掉点章修法 + 梗库增量 | 更新 `19/10` 清单与 `06_感情梗库` |
| 完结复盘 | 每本 | 18_完结复盘全项 + 题材包效果评估 | 更新题材包 + 宪法 + 框架版本 |
| 季度刷新 | 每季度 | 题材热度雷达刷新 + 番茄新口径核对 | 更新 `19/12` 与 `19/08` |

## 回流物清单（哪些经验值得写回框架）

1. **题材包效果**：某题材包节奏配置是否成立（爆/扑）→ 改配置
2. **梗/名场面**：读者高共鸣点 → 入梗库
3. **钩子类型**：实测最留人的钩子 → 入题材包"常用钩子"
4. **硬规则**：反复出现的错 → 入错误禁令清单
5. **读者评论高频词**：下一本书名简介直接用
6. **平台新口径**：红线/活动 → 更新适配规则

## 框架版本规则

- 每次更新登记 `03_框架版本历史.md`：版本/日期/改动内容/依据/验证结果
