# 【书名】｜读者承诺与差异化设计

状态：ACTIVE / FRAME_R5 / 2026-10-21

用途：【书名】｜读者承诺与差异化设计。本轮为证据化质量升级；用于新项目配置与验收，不新增《偏航》剧情事实。
依赖：项目配置、作者设计说明、章节合同与质量证据。使用：按本页步骤产出表中记录，再进入下一关。

## 六句立项卡

1. 为哪一类读者写：最近爱读什么、想获得什么、明确不能接受什么。
2. 她一眼认得的熟悉入口：题材承诺，不堆十个热词。
3. 本书独有的矛盾：谁想要什么，却必须付出自己最怕的代价。
4. 为什么现在发生：触发事件令旧平衡再也维持不了。
5. 前三章可看见的独有行动：不能只把差异化藏在十万字后。
6. 三十万字的持续回报：重复的是情绪承诺，升级的是选择和后果。

“女主聪明”“男主疯批”“更爽”不算差异化；换成只有这套身份、资源、欲望才能做出的动作。移除姓名仍像任意同类书，返修。
选三个同期同题材与相近字数阶段样本，含普通表现样本；公开热度只记录可见值，不能据评论数量编造留存。榜单样本存在幸存者偏差。

## 包装一致性

书名、封面、简介承诺 → 第一次兑现章 → 关系结构与终局。五处逐项对齐。作者偏好字数作为约束，平台实际长度限制另核。包装可吸睛，不能用正文不存在的关系或身份骗点击。
