# 19_11｜书名·简介·标签模板

状态：ACTIVE / 开书前定稿
用途：让作品在推荐算法与读者 3 秒判断里被点开。

## 一、书名公式（择一组合）

1. **身份反差式**：【低姿态身份】×【隐藏王炸】（例：被赶出豪门的千金是黑客大佬）
2. **关系钩子式**：【关系】+【悬念】/【情绪】（例：闪婚老公是顶流，他却宠我入骨）
3. **事件爆点式**：【动作】+【结果】/【反转】（例：重生后我踹了渣男，他跪着求复合）
4. **萌点/反差式**：【萌元素】+【关系】（例：带球跑后，我成了首富的心尖宠）

规则：作者可先试短书名（如12字内）；可含一个准确的题材词（追妻/马甲/闪婚/重生/团宠/萌宝…）；不剧透终极真相；中文符号规范。

## 二、简介公式（三句三层）

```
第一句：女主身份/处境一句话（让人代入或好奇）
第二句：核心冲突/长线钩一句话（她知道什么、读者等她做什么）
第三句：爽点/结局暗示一句话（打脸/糖/团圆，让人有预期）
```

示例骨架：她【低姿态身份】，【被设计处境】。没人知道她其实是【王炸身份】。直到【首个名场面】——所有人傻眼。【关系线钩子】。
规则：100—200 字；不写设定说明；末尾留钩；含书名关键词。

## 三、标签选择

- 主分类 1 个（题材包对应分类：豪门总裁/宫斗宅斗/职场婚恋/青春甜宠…）
- 设定标签 2—3 个（先婚后爱/追妻火葬场/隐藏马甲/团宠…）
- 情绪标签 1—2 个（甜宠/虐恋/爽文…）
- 规则：标签与正文前 30 章实际内容一致（防"标签诈骗"掉推荐）

## 四、开书前三件套自检

- [ ] 书名：符合作者长度偏好与实际平台限制 + 准确题材词 + 不剧透
- [ ] 简介：三句三层 + 有钩 + 100—200 字
- [ ] 标签：主分类 + 设定 + 情绪，与前 30 章一致
