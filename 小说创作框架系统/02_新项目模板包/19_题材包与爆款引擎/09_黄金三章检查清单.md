# 19_09｜黄金三章检查清单

状态：ACTIVE / 每本开篇必过
依据：番茄官方黄金三章法则（2026-04）

## 使用说明

开篇三章写完（R001 后）逐项自检，全部"通过"才进入正式评审；不通过先改开篇，不改正文。

## 第一章：抛核心冲突

- [ ] 开场 300 字内进入事件（禁止背景/家世/环境长铺垫）
- [ ] 核心冲突一句话可复述（读者 3 秒能懂"她正在倒霉/危险/不甘心"）
- [ ] 女主处境让读者"为她憋屈/担心/好奇"
- [ ] 有至少一个"反常识/反差"信息（立人设或立悬念）
- [ ] 章末钩子：冲突未解决或升级（禁止平淡收尾）

## 第二章：亮金手指/底牌

- [ ] 女主底牌/金手指/独特能力首次亮相（不藏着掖着）
- [ ] 底牌在"实际交锋"中使用（禁止只介绍不演示）
- [ ] 底牌附带代价或边界（防无脑开挂）
- [ ] 底牌引出长线悬念（她为什么有这能力/这身份）

## 第三章：明确短期目标 + 小爽点

- [ ] 女主定下"近期小目标"（读者有期待路径）
- [ ] 第一个小爽点实际兑现（打脸/反转/护住什么）
- [ ] 目标与长线主线关联（不是孤立支线）
- [ ] 章末留下"下一章想看的点"

## 通用（三章全过）

- [ ] 三章内至少 1 个名场面级情绪峰值
- [ ] 出场人物 ≤5，每人有台词作用
- [ ] 无设定说明书（背景融入行动与对话）
- [ ] 对标题材包"黄金三章设计"逐项一致
