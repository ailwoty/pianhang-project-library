# 新项目启动与日常执行手册

状态：ACTIVE / FRAME_R5 / 2026-10-21

用途：新项目启动与日常执行手册。本轮为证据化质量升级；用于新项目配置与验收，不新增《偏航》剧情事实。
依赖：项目配置、作者设计说明、章节合同与质量证据。使用：按本页步骤产出表中记录，再进入下一关。

## 启动

1. 复制整个模板包；同时重命名文件名及文件正文中的`【书名】`。不要只改内文漏改母版路径。
2. 完成读者定位卡和作者设计说明；选择题材包并明确不采用的条款。
3. 填`15_数据资产与机器可读/项目配置.json`，检查总章数=卷数×每卷章数、目标字数=总章数×目标均字。
4. 填通用宪法的作者锁定区，再填母版、人物、关系节点、卷与前三章合同。
5. 注册实际实体；空表不冒称已注册；所有正文进度从0开始。
6. 生成前三章原型，按正文标记契约写入，运行机器检查和内容审核。
7. 冻结版本，做试读与连续10章续航检查；记录尚未完成的真人和市场验证。
8. 再评估发布准备，核当期实际平台要求与产能；不把写原型和正式发布混成一道门。

## 每章最短路径

前置五查→章节合同与场景卡→先建修改记录→起草→机器检查→八轮内容检查→缺陷修复→冻版评审→五处状态同步。实际读文件数由涉及设定决定，不谎称固定五六件。

## 质量目标

12维每维9.9为内部目标档，具体证据和否决项见11域；真人、市场未验要如实记录。不得为了提高数字删去异议，或宣布百分百爆款。

## 验证

在模板包根运行：

```bash
python 16_自动化与校验工具/框架体检.py --root .
python 16_自动化与校验工具/硬规则校验器.py 正文文件.md --config 15_数据资产与机器可读/项目配置.json
python 16_自动化与校验工具/一致性回归检查.py --body 正文目录 --registry 15_数据资产与机器可读/01_实体图谱.csv
python -m unittest discover -s 16_自动化与校验工具/tests -v
```

首个命令为框架结构体检，不检验文学表现。第二个检查明确的文本规则。第三个只统计已注册实体、检查禁词，不识别全部未知人名、语义或时间矛盾。第四个为工具正反例测试。
构建/完结期用18域；反馈回流用20域；真人试读与数据解释用22域。未启用模块允许按路由裁剪，但须更新资产清单和配置。
