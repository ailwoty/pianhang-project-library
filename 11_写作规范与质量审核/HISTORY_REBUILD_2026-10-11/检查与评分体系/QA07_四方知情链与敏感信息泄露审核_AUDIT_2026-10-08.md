## 1. 一条信息至少要走七跳

`节点事实→发生时点→首次可知主体→可使用渠道→可验证证据→首次转述/行动→行为后果`。

不能把“读者知道”写成“黎栖雾知道”，不能把“容既白有资格看索引”写成“能把所有内容告诉她”；若上游缺失，标`SOURCE_UNKNOWN`而不是编补。

## 2. 第一章09-A核验

| 主体 | R003结束时可确认 | 不得推断 |
|---|---|---|
| 读者 | 09-A作为索引节点出现；保全提示刷新 | 原件仍在、谁拿走、谁造假、缺失真实原因 |
| 黎栖雾 | 她的权限范围内看见09-A标签和不可见字段 | 她已经知道具体内容或有复制权 |
| 容既白 | 本章能通过法务接口提供授权视图、解释“只能证明索引存在” | 不能推断他知晓所有未知内容/旧情真相 |
| 内部其他人 | 经部门职责可接触部分保全流程 | 哪些部门人员确切看过09-A内容：UNKNOWN |

`FACT_000005_v1`保留`TITLE/CONTENT/CURRENT_HOLDER/MISSING_REASON=UNKNOWN`；`EVID_000002`只记录授权索引视图。此范围内Q02应判`PASS_OBSERVED`。**若第二章让任何人直接说出09-A的具体内容，必须交代合法新增知情路径。**

## 3. 五个否决触发器

1. **无渠道获得秘密**：人物直接识别Q、白噪或六年撤离细节，而INFO/正文没有来源，优先P1，明确CANON冲突P0。
2. **渠道不等于全文授权**：知道档案编号不等于读过全文；保全不等于恢复访问。
3. **猜测升级事实**：人物私下怀疑可以写，但叙述标签必须保留`CLAIM/INFERENCE`，不得变`FACT`。
4. **时代错置**：六年前发生的事、六年期间获知的事、回归当日看到的事分时点，不允许倒填。
5. **旁白越权**：有限视角中的“他显然知道”“所有人都清楚”应查证是否只是女主的推断。无证据时改为受限感知，不向男主偷发知识。

## 4. 审核工单结构

`INFO_CHAIN_ID / INFO_FACT_ID / FACT_TIME / READ_AUDIENCE / LQW_ACCESS / COUNTERPART_ACCESS / OTHER_ACTORS / LEGAL_CHANNEL / ONPAGE_OBSERVATION / RELIABILITY / UNANSWERED_FIELDS / DECLASSIFICATION_EVENT / CONSEQUENCE / REVIEW_VERDICT`。

每个字段附CURRENT来源或精确文本锚；未露出的秘密无需预填完整值。涉Q/白噪/南岬/雾港必须用最新对应主账，当前文件不宣告具体身份或真相。
