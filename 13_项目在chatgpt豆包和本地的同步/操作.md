
1. 第一次将本地文件夹上传到github
New repository
git init
git add .
git commit -m "首次上传项目"
git branch -M main
git remote add origin https://github.com/ailwoty/songhu.git
git push -u origin main
2. 本地文件变动同步：
git add .
git commit -m "update project library"
git push
3. 远程和本地都更新了，怎么将本地上传：
git pull --no-rebase --no-edit origin main
git push origin main
4. 将远程同步到本地：
git pull
